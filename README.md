# LineUP — Sprint 4

Evolução da Landing Page da Sprint 03 integrada ao React.

## Tecnologias utilizadas

- React + Vite
- React Router DOM
- Tailwind CSS
- API pública Picsum Photos (https://picsum.photos)
- Git + Vercel

## Como instalar as dependências

É necessário ter o Node.js instalado (versão 20.19 ou superior).

```bash
npm install
```

## Como executar o projeto

```bash
npm run dev
```

Depois, abra no navegador o endereço exibido no terminal (normalmente http://localhost:5173).

## Como executar os servidores

O projeto não possui Back-end. Os dados são consumidos diretamente da API pública Picsum Photos.

## Uso de IA no projeto

Utilizamos IA generativa (Claude, da Anthropic) como apoio na migração da Landing Page da Sprint 03 para o React: ela ajudou a dividir a página em componentes, a criar as rotas públicas e privadas, a escrever os hooks customizados (`useAuth` e `useCapturas`) e a redigir a primeira versão deste README. O conteúdo da solução (textos, imagens, protótipo e identidade visual) foi produzido pela equipe, e o código gerado foi revisado e testado pelos integrantes.
